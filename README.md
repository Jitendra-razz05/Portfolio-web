# Jitendra Rajpurohit Portfolio

## Files
- `index.html` — main portfolio
- `style.css` — responsive premium UI
- `script.js` — menu, scroll progress and reveal animations
- `resume.html` — resume page connected to portfolio
- `resume.css` — resume styling
- `resume.js` — PDF download
- `thank-you.html` — form success page

## Contact form
The contact form uses FormSubmit and is configured to send submissions to:
`jitendrarajpurohit004@gmail.com`

### Important before deployment
1. Replace `https://YOUR-PORTFOLIO-DOMAIN/thank-you.html` in `index.html` with your real deployed URL, for example:
   `https://yourdomain.com/thank-you.html`
2. On the first form submission, FormSubmit may ask you to confirm/activate the receiving email address.
3. After deployment, test the form from another email address.
4. The portfolio and resume links are already connected using `index.html` and `resume.html`.

## Run locally
Open `index.html` with VS Code Live Server, or deploy the folder to Vercel/Netlify/GitHub Pages.
